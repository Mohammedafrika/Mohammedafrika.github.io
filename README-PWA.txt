MOHAMMED AHMED — INSTALLABLE ANDROID PWA

This package adds PWA install support and offline caching to the existing website.

UPLOAD TO GITHUB PAGES
1. Extract this ZIP on your phone.
2. Open the repository: https://github.com/Mohammedafrika/Mohammedafrika.github.io
3. Choose Add file > Upload files.
4. Upload/replace the CONTENTS of the mohammed_ahmed_website folder into the repository root. Keep the assets folder and its files together. Do not upload the outer folder itself.
5. Commit changes to the main branch.

The repository root should contain:
- index.html
- manifest.webmanifest
- sw.js
- assets/profile.jpg
- assets/icon-192.png
- assets/icon-512.png
- assets/icon-512-maskable.png

INSTALL ON ANDROID
1. Open https://mohammedafrika.github.io/ in Chrome.
2. Tap the three-dot menu.
3. Choose Install app or Add to Home screen, then confirm.

The app shell can open offline after it has loaded once online. Social links and email still need an internet connection. GitHub Pages must remain enabled for the main branch and root folder.
